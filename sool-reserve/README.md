# SOOL RESERVE · 술의 격

프리미엄 전통주 큐레이션 편집숍. 1단계(브랜드 사이트) + 2단계(관리자·데이터·수익성)를 구현했고, 3단계(주문·결제·정산)는 데이터 모델과 판매 게이트만 준비되어 있습니다.
설계 기준은 [`SPEC.md`](./SPEC.md)를 참고하세요.

## 1. 빠른 실행

### Replit
1. 이 저장소를 Replit으로 가져온 뒤 **작업 폴더를 `sool-reserve`로 지정**합니다 (또는 이 폴더만 별도 Repl로 가져오기).
2. Tools → **Database(PostgreSQL)** 를 추가하면 `DATABASE_URL`이 자동 설정됩니다.
3. Tools → **Secrets**에 아래 값을 추가합니다.

| 키 | 값 |
|---|---|
| `SESSION_SECRET` | 32자 이상 임의 문자열 (필수) |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | 최초 관리자 계정 (미설정 시 아래 기본값) |
| `SITE_URL` | 배포 주소 (사이트맵·canonical용, 선택) |
| `PG_SECRET_KEY`, `AGE_VERIFICATION_SECRET` | **비워 두세요.** 비어 있으면 실결제·실인증 경로가 존재하지 않습니다 |

4. **Run** → `npm install → DB 마이그레이션 → 데모 시드 → 개발 서버` 순으로 실행됩니다.

### 로컬
```bash
cp .env.example .env          # DATABASE_URL, SESSION_SECRET 수정
npm install
npm run setup                 # 마이그레이션 + 관리자 계정 + 데모 데이터
npm run dev                   # http://localhost:3000
```

## 3. 주요 기능

**고객 사이트** — 메인 8섹션, 전체 컬렉션(검색·주종/맛/상황/가격 필터·정렬), 상품 상세(기본정보·맛 레이더·양조장 스토리·음용가이드·페어링·선물·배송), 양조장, 명인주, 리미티드, 프리미엄 기프트, 취향 추천(5문항), 기업 VIP 상담, 브랜드 스토리(+정보 구독), 입점 문의, 고객센터, 법적 고지, 사이트맵·구조화 데이터

**매거진** — 6개 카테고리(명주 이야기·장인 인터뷰·선물 가이드·페어링·보관 가이드·양조장 탐방), 목록·본문·연결 상품, 홈 Journal 섹션, 구조화 데이터(Article)

**사진 슬롯** — 실사진이 없으면 일러스트로 자동 대체, 업로드하면 즉시 교체
| 위치 | 업로드 화면 | 미등록 시 |
|---|---|---|
| 메인 히어로 | 시스템 설정 → 브랜드 | 병 일러스트 |
| 상품 대표 + 추가 사진(최대 8장) | 상품 관리 | 주종별 병 일러스트 |
| 양조장 대표 사진 | 양조장 관리 | 테마 일러스트 10종 중 선택 |
| 장인 사진 | 양조장 관리 | 실루엣 일러스트 |
| 제조 과정 사진 6장 + 캡션 | 양조장 관리 | 6단계 공정 일러스트 |
| 매거진 커버 | 매거진 | 카테고리별 일러스트 |

**관리자** — 수익 대시보드, 수익성 분석, 양조장 입점 7단계·서류 검토·판매 활성, 상품 CRUD(이미지 업로드·맛·배송·선물·수익 구조·선별 점수), 목록에서 가격·재고·상태 즉시 수정, 상품 선별(조건 필터 → 추천 슬롯 추가), 추천 슬롯 5종, 매거진 CMS(광고 기준 5개 항목 점검 전 게시 불가·예약 게시), 문의 관리, 법적 고지 버전 관리(시행일 자동 전환), 시스템 설정(브랜드·운영 모드·가격 구간·수수료·가중치·사업자 정보), 계정·권한, 변경 이력

**파트너 센터** — 자사 상품 등록(검토 대기로 등록)·수정, 재고 즉시 수정, 양조장 스토리 편집, 주문·정산(판매 활성화 후)

## 5. 수익 계산 (단일 소스: `src/lib/economics.ts`)

```
기준금액     = VAT 포함 ? 판매가 : floor(판매가 / 1.1)
수수료 수익  = round(기준금액 × 수수료율)
공헌이익     = 수수료 수익 − 플랫폼 부담 결제비 − 배송·포장비 − 프로모션 − 기타 변동비
공헌이익률   = 공헌이익 ÷ 수수료 수익 × 100
판매자 정산  = 판매가 − 수수료 − (판매자 부담 시) 결제비
수수료율     = 상품값 → 양조장 기본값 → 시스템 기본값
```
대시보드 금액은 실거래가 없으므로 **상품별 '예상 월 판매량'(관리자 입력)** 기준 추정치입니다.
